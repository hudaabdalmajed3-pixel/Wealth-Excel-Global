## 📌 Project Overview
**Wealth Excel Global** is a comprehensive, multi-lingual web-based financial and investment platform built as a Progressive Web App (PWA). It is designed to manage investment portfolios, track daily profits, and build dynamic referral networks with a strong emphasis on high security, precise automation, and a modern user experience.

## 🚀 Key Technical Achievements

- **Smart AI KYC (Liveness Detection):** Integrated `@tensorflow/tfjs` and `face-api.js` directly into the browser for real-time facial recognition, liveness detection, and identity verification.
- **Mandatory PWA Gate:** Engineered a standalone installation gate that blocks standard mobile browser access, forcing users to install the PWA for a highly secure, app-like environment.
- **Fractional Deposit System:** Developed a smart algorithm that generates unique fractional decimal numbers for every transaction, enabling precise, automated tracking of digital deposits (e.g., TRC20).
- **Automated Financial Operations:** Built a time-based daily task system that automatically calculates and distributes ROI to user wallets, alongside an instant tech-reinvestment feature.
- **Dynamic Referral Architecture:** Designed a complex relational database to track multi-tier referral networks, calculate member activity, and trigger automated incentive rewards based on custom targets.
- **Advanced Security Measures:** Implemented robust security standards including OTP email verification (via SMTP), secure session management, middleware protection, and password hashing.
- **Modern UI/UX:** Developed a fully responsive interface featuring Glassmorphism, Dark Mode support, and seamless RTL/LTR switching for Arabic and English users.
