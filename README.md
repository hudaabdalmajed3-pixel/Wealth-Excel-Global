## 📌 Project Overview
> **Wealth Excel Global** is a comprehensive, multi-lingual web-based financial and investment platform built as a Progressive Web App (PWA). 

It is designed to manage investment portfolios, track daily profits, and build dynamic referral networks with a strong emphasis on high security, precise automation, and a modern user experience.

---

## 🚀 Key Technical Achievements

| Feature | Description |
|---------|-------------|
| 🤖 **Smart AI KYC** | Integrated `@tensorflow/tfjs` & `face-api.js` for real-time facial recognition and liveness detection. |
| 📱 **PWA Gate** | Engineered a standalone installation gate blocking standard mobile browser access for a highly secure, app-like environment. |
| 🧮 **Fractional Deposit** | Developed a smart algorithm generating unique fractional decimals for tracking digital deposits (e.g., TRC20). |
| ⚙️ **Automated Ops** | Time-based daily task system that automatically calculates & distributes ROI, alongside an instant tech-reinvestment feature. |
| 🌐 **Dynamic Referrals**| Designed a complex relational database tracking multi-tier referral networks and triggering automated incentive rewards. |
| 🔒 **Advanced Security**| Implemented OTP email verification (SMTP), secure session management, middleware protection, and robust password hashing. |
| 🎨 **Modern UI/UX** | Developed a fully responsive interface featuring Glassmorphism, Dark Mode, and seamless RTL/LTR switching. |
